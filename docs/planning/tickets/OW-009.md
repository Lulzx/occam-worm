## Deliverable

C++ scalar reference interpreter for G0/G1 and a differentiable Python (JAX or PyTorch) simulator with identical semantics: chemical/gap coupling, delays, history-conditioned initial state and observation integration.

## Done when

Both implementations pass the conformance suite and agree with each other to tolerance, including permutation equivariance and timestep checks.

## Result

**C++ half (done).** `libs/ow-sim` is a scalar, bounds-checked, deterministic reference interpreter for G0/G1 with synchronous old-state semantics, per-edge integer delays with a history ring, a semi-implicit gap-junction stage, `identity_v1` and `calcium_linear_v1` observation and exact sampling. Run it with `ow sim run --program X --case Y`; run the oracle with `ow sim conformance --suite tests/conformance` (CTest `conformance_suite`). The exact formulas, JSON formats, timestep order, delay-ring and history rules, gap discretisation and the Philox plan for later stochastic tiers are in [WRL_SYNTAX.md](../../language/WRL_SYNTAX.md) §6 and summarised in the "Implemented (OW-009)" note of [SIM_SEMANTICS.md](../../runtime/SIM_SEMANTICS.md).

**Conformance suite.** 52 self-contained cases in `tests/conformance/` with analytic or hand-derived expectations (generator: `tests/conformance/gen_cases.py`, see its README for the case list): chemical excitation and inhibition, gap diffusion and constant equilibrium, delay ring wraparound, history initialisation, adaptation, calcium filter and sampling, constant/impulse/zero stimuli, edge deletion, G0 truth tables, type masks and observed masks, permutation equivariance, dt versus dt/2 convergence, and compile-time rejections. The C++ interpreter passes all 52. Property tests (`tests/cpp/test_sim.cpp`) add random-graph relabelling equivariance, independence of disconnected subnetworks, zero-edge graphs and symmetric subgraphs.

**Python half (done).** [`python/occamworm/sim/`](../../../python/occamworm/sim/README.md) implements §6.8 with two separate implementations that consume the IR JSON of `ow rule inspect` (`ir.py` loads and validates it and obtains it from the `ow` binary: `$OW_CLI`, else `build/clang/libs/ow-cli/ow`, with a clear error when missing; `graph.py` and `cases.py` load graphs, stimuli, inputs and conformance cases): `reference.py`, a plain scalar interpreter (Python floats, loops, no numpy), and `jaxsim.py`, a float64 differentiable simulator (`jax.lax.scan`, history ring, edge-list gathers with `segment_sum`, node-local semi-implicit gap step, `vmap` over trials, stimuli, initial states and parameter vectors, `jax.grad` through time).

**Conformance results.** `tests/conformance/test_python_conformance.py` runs all 52 cases through both implementations (214 tests with the binary present):

| Check | Result |
|---|---|
| 36 `traces` cases against the analytic expected values with each case's own tolerance | 36/36 in the scalar interpreter, 36/36 in JAX |
| 2 `permutation`, 2 `convergence` cases (dt, dt/2, dt/4 ratios and finest error) | 4/4 in both |
| 12 `compile_error` cases | `ow` rejects all 12 with the expected code; Python never sees IR for them (no IR is cached) |
| scalar interpreter against `ow sim run` on every run of every case | maximum deviation 0 (bit-identical) |
| JAX against `ow sim run` | maximum deviation 4.4e-16 |
| JAX against the scalar interpreter | maximum deviation 4.4e-16 (limit 1e-12) |
| random graphs (6 per rule, `leak-adapt`, `leak-adapt-euler`, `gap-leak`, `rule90`; random delays, signs, weights, masks, sampling) | all three implementations agree to 1e-12 |
| JAX gradients against central finite differences (3 programs: calcium observation with adaptation, gap with delay and sigmoid, Euler with clamp/abs/max) for `theta`, stimulus and initial state | relative error below 1e-6; batched gradients equal the sum of single-trial gradients |

Without the binary, the traces, permutation and convergence cases still run from a committed IR cache (`tests/conformance/ir_cache/`, keyed by SHA-256 of the source, a freshness test compares it with the compiler when the binary is present; `OW_UPDATE_IR_CACHE=1` rewrites it); the C++ agreement and compile-error tests are skipped with a reason.

**Discrepancies between the documents and the C++ interpreter:** none found. One implementation note: JAX cannot raise `E_RUNTIME` inside a jitted scan, so non-finite values propagate and `jaxsim.simulate` raises `SimulationError` after the run.

**Speed** (Apple M4 Pro CPU, random 302-neuron graph, 7,000 chemical edges, 1,500 junctions, 2,000 steps): JAX about 8,900 steps/s forward, about 5,900 steps/s forward plus gradient, about 31,000 trial-steps/s for a batch of 8; scalar Python about 75 steps/s; `ow sim run` about 7,800 steps/s including process start.
