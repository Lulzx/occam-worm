## Deliverable

B4 with fixed topology, constrained edge weights and stable integration.

## Done when

Reproduces toy analytical solutions and participates in identical outer-fold scoring.

## Progress

- [x] B4-fixed (τ, gap scale and one chemical gain) and B4-learned (a tanh gain per presynaptic neuron) on `cook2019-herm`. The matrix is A = −I/τ + W + g·L, with row-normalized counts, so it is Gershgorin-stable for every parameter value. Kernels are exp(A t)·b at the tent knots; fitting uses JAX with L-BFGS-B. Pairs whose labels do not resolve to a canonical neuron get a zero kernel.
- [x] Toy analytical solutions (`tests/synthetic_truth/test_linear_network.py`): a single synapse gives an exponential, a two-synapse chain gives an alpha function, and a gap pair gives two modes. The network stays stable at extreme parameters, and the time constant is recovered from synthetic traces.
- [x] Takes part in identical outer-fold scoring: B4 is a family of the same benchmark, scored on the same folds by the same machinery.
- [ ] Full-benchmark result.

Deviation: the input is fed through the target's postsynaptic and gap partners, and the target's own state is not clamped (declared approximation). Development folds: the B4 training loss is close to B0 and far from B3, so on this data anatomy alone is a weak predictor.
