## Deliverable

Downloader/import wrapper and `sources.json` with DOI/URL, byte hash, retrieval metadata and license field.

## Done when

A clean environment verifies the checksum of each accessible raw resource and reports missing/unlicensed assets explicitly.

## Progress

- [x] Registry `configs/datasets/sources.json`: 14 sources, 696 assets. OSF assets pinned by upstream sha256; Zenodo by md5; GitHub sources by commit.
- [x] `python -m occamworm.sources {list,fetch,verify,pin,refresh}`, stdlib only. See [ACQUISITION.md](../../data/ACQUISITION.md).
- [x] `verify` reports missing, mismatched, unpinned, untracked and unlicensed assets; exit code 1 on any integrity failure.
- [x] License evidence recorded per source. The atlas and Atanas & Kim data declare no license; the Leifer Lab and Worm Neuro Atlas code is GPL-3.0.
