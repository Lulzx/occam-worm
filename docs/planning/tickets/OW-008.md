## Deliverable

Typed parser, canonical IR, complexity bits and source serializer.

## Done when

Invalid unit expressions fail and canonical hashes are identical for known equivalent expression reorderings.

## Result

Implemented in `libs/ow-core` (units, typed graph in CSR, SHA-256, JSON) and `libs/ow-ir` (lexer, parser, unit/type/tier/stability checker, canonical IR, program hash, `L_struct`/`L_params`, source serializer, IR JSON). `ow rule inspect <file>` prints the canonical IR JSON, `ow rule canon <file>` the hashed canonical source. The concrete syntax (line-oriented, no YAML) and the IR schema are in [WRL_SYNTAX.md](../../language/WRL_SYNTAX.md); example rules are in `configs/rules/`.

- **Invalid unit expressions fail:** adding seconds to a dimensionless value, `tanh` of a unit-carrying value, mismatched `next` units and similar cases are rejected with `E_UNIT` (`tests/cpp/test_ir.cpp`). The explicit-Euler primitive is rejected with `E_STABILITY` when `dt_max / tau_lower > 1` for the declared bounds (`configs/rules/rejected/leak-euler-unstable.wrl`).
- **Equivalent reorderings hash identically:** `a+b` / `b+a`, `(a+b)+c` / `a+(b+c)` / `c+(b+a)`, renamed locals, registers and parameters (and their declaration order), dead lets, dead registers and unused parameters, inlined locals, constant folding, `a-b` / `a+(-b)`, `max(x,0)` / `relu(x)`, CSE; non-equivalent pairs hash differently. Canonicalisation is idempotent (the canonical source is itself valid WRL and recompiles to the same hash).
- **Bit accounting:** frozen prefix-free code (version 1) with a per-component breakdown in the IR JSON, charged precision in `L_params`, and a hand-computed unit test.
- **Parser robustness:** deterministic mutation test in CTest and a libFuzzer target in `tests/fuzz/` (see [REPRODUCIBILITY.md](../../engineering/REPRODUCIBILITY.md#local-build-and-test) for the commands and the fuzzing record below).
- Grammar version and compiler build string are stored in every IR JSON.

Deferred: G2+ tiers, `mean_in`, `sum_mod`, `piecewise`, stochastic operators, value-dependent `L_params`.
