## Deliverable

Plots and Markdown report generated only from frozen run artifacts.

## Done when

A published table cell is traceable to its exact model, fold, sample IDs and code hashes.

## Notes

Reports for OW-014 outputs (intervention rankings) are added once OW-014 lands; the minimum viable engine needs OW-015 without OW-014.

## Progress

- [x] Content-addressed runs (§14.7). Each run directory starts with `run.json`, which records the input hashes (dataset manifest, eligibility table, split, graph, experiment config), the code revision with a dirty flag, the seeds and the families. The `run_id` is the hash of these. A resumed run with different inputs is refused.
- [x] `python -m occamworm.analysis freeze --run DIR` records the sha256 of every file. `report` builds only from frozen runs whose files still match and refuses anything else.
- [x] Every table number is a cell with an id. `provenance.json` maps the id to the run id, model (task, history variant, family, ridge per fold), outer folds, held-out animals, scored trial ids, code revision and input hashes. `trace(report_dir, cell_id)` returns that record.
- [x] Dependency-free SVG figures (forest plot of paired animal-level differences, line plots).
- [x] Done-when test: every cell in a generated report traces to model, folds, sample ids and code hash, and the B3 NLL cell reproduces its folds and trial ids exactly. Modifying an artifact after freezing makes the build fail.
