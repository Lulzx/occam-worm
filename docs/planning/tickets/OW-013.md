## Deliverable

Explicit neuron/edge annotation adapter using OpenWorm/Worm Neuro Atlas and unresolved-ID audit.

## Done when

Conflicting annotations show provenance/uncertainty instead of forced binary assignments.

## Result

`python -m occamworm.importers annotations build` verifies both sources, then writes `data/normalized/annotations-v1/`: 302 canonical neurons, a versioned alias table (400 rows), 179,295 typed edge rows from 23 reconstructions kept side by side (30,782 chem, 10,922 gap, 3,161 nmj, 134,430 putative_mod), 154 conflicts with both values and sources, and an audit of all 309 distinct atlas labels (206 exact, 1 alias, 74 ambiguous, 28 unresolved). The functional, anatomical and molecular intersection is 194 neurons. Rules, counts and open issues: [ANNOTATIONS.md](../../data/ANNOTATIONS.md).

- Conflicting annotations keep every value, its source and member, and a `conflicts.parquet` row (73 neuron conflicts, 81 edge-weight conflicts between bundles); none is forced into one value.
- Sign is `unknown` for every edge except the Fenyves 2020 predictions (1,327 excitatory, 425 inhibitory), which carry `sign_basis` and the raw label. No sign comes from a presynaptic cell name.
- The Worm Neuro Atlas is GPL-3.0: only its data files are read, by readers written here.
