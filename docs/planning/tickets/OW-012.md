## Deliverable

Inner-fold search, candidate ranking, immutable freeze, locked outer evaluation.

## Done when

No test labels are reachable from the search API and leak-injection tests fail as expected.

## Progress

- [x] Training-only views (`search/views.py`): each fold gets copies of the training animals' data, with no memory shared with the full dataset.
- [x] Inner-fold search with ranking by inner-validation NLL. Ties go to the shorter `L_total`. The (`L_total`, NLL) Pareto front is kept, and the search log records every attempted and rejected candidate (§7.8).
- [x] Immutable freeze (sha256 plus the hash of the training animals) and a locked outer evaluator that scores each fold once.
- [x] WRL programs as candidates (`search/wrl.py`). Each runs on `cook2019-herm` through the JAX simulator. Its linear response to a small pulse gives pair kernels on the shared tent basis, so it is fitted and scored by the same machinery as B0–B4. Programs pass structural and stability gates before any fit. Enumeration uses `ow search enumerate`; a budget curve with a random-order control covers §7.8.
- [x] Done-when tests (`tests/leakage/test_search_leakage.py`): no held-out data reaches the search API. Injected inner leaks, tampered selections, selections trained on held-out animals and second scorings all raise `LeakageError`. In `tests/synthetic_truth/test_wrl_candidate.py`, a WRL program recovers its generating parameters and wins a synthetic nested search.

Result: [SEARCH_DEMO.md](../../evaluation/SEARCH_DEMO.md) (`configs/searches/atlas-demo.json`, LOAO outer folds 0–2, T2a). It offers 13 candidates per fold:

- the kernel baselines B0, B1 and B3;
- the hand-written rules `gap-leak` and `leak-adapt`;
- the first 8 of 28 programs that pass the gates, out of 400 enumerated (296 inert, 76 uncoupled).

B3 wins every fold. The Pareto front is the same on all three: `b59c084287fa` (a 64-bit excitatory relay), `gap-leak` (150 bits), B1 (870k bits) and B3 (9.7M bits). `gap-leak` closes about half of the inner-NLL gap between B0 and B3 on each fold (46%, 53% and 37%). The chosen ridge is interior to the grid.

Deviation: the search is implemented in Python (`python/occamworm/search/`), not in `libs/ow-search/`; enumeration and canonicalization stay in C++.
