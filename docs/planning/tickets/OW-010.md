## Deliverable

Length-limited grammar enumeration, stable ordering, canonical cache.

## Done when

All finite programs within a small predefined grammar budget are visited exactly once up to canonical equivalence.

## Result

`ow search enumerate --config configs/searches/<name>.json` (`libs/ow-search`) enumerates a length-limited grammar (`max_nodes`, `max_depth`, `max_registers`, `max_parameters`, per-tier operator allowlist) in a stable order, sends every candidate through the real compiler (type, unit, stability gates), deduplicates by canonical program hash and emits JSON lines (`hash`, canonical `source`, `l_struct`, `l_params`) plus a summary of every attempted candidate. Grammar and ordering: [WRL_SYNTAX.md](../../language/WRL_SYNTAX.md) §8. Configs: `g0-tiny.json`, `g1-tiny.json`.

**Done-when evidence** (`tests/cpp/test_search.cpp`): the enumerator's canonical hash set equals the hash set of an independent brute force (raw prefix-token sequences rendered to source and compiled), and no hash is emitted twice.

| `g0-tiny` | 15,940 | 9,368 | 3,921 | 5,447 | 0 | 0 |

| two-register G1 test config | 16,411 | 9,777 | 2,755 | 3,609 | 0 | 3,413 |

Deferred: the dynamic finite-output gate on a synthetic graph ([§7.3](../../inference/SEARCH_AND_INFERENCE.md) step 3), structured mutation and the persistent search log (OW-012).
