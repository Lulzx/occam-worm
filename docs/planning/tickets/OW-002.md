## Deliverable

Python importer over official `Funatlas`/`Fconn` data with stable animal/trial/responder identifiers, raw trace links, stimulation order within each recording, and the stimulated neuron's trace stored as a separate input channel.

## Done when

Randomly sampled normalized observations round-trip to the official trace data with preserved timing and values within documented transforms.

## Notes

The importer reads the official files directly instead of calling `Funatlas`/`Fconn`: pumpprobe is GPL-3.0 and its pickles would execute upstream code. Pickled metadata is read with an allowlist unpickler. Formats, codes, the upstream −3 bug and the trace-source rule are documented in [RANDI2023_IMPORT.md](../../data/RANDI2023_IMPORT.md).
