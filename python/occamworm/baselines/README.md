# `occamworm.baselines`

Baselines B0–B6, each in history and no-history variants, scored on T2a and T2b.

**Invariant:** Every baseline gets a defensible tuning budget and the same observation model where feasible.

**Planned contents:**

- `null.py` — B0
- `shared_kernel.py` — B1
- `lowrank_kernel.py` — B2
- `independent_kernel.py` — B3
- `linear_network.py` — B4
- `history.py` — stimulation-history terms
- `indicator.py` — indicator kinetics and control
