# `occamworm.experiments`

Intervention menu entries and expected-information-gain ranking by predictive Monte Carlo under the fitted AR(1) measurement noise (§8.3), with a Monte Carlo standard error on every estimate. Outputs are research suggestions (§8.4).

Implemented in Python rather than `libs/ow-experiments/` (§14.1).
